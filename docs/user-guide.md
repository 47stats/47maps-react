# 47maps ユーザーガイド

このガイドでは、47mapsの基本操作を説明します。はじめて利用する場合は、まず「階級図を見る」から操作を始めてください。

## 画面イメージ

<img :src="'./47maps-react.png'" alt="47mapsの画面例">

地図の上に統計データを重ねて表示し、左上メニューから階級図表示、商圏登録、設定を切り替えて操作します。

## できること

- 統計データを地図上に重ねて表示する
- 地域を選択して比較する
- 商圏を円商圏または到達圏で登録する
- 設定を保存・復元する

## 画面の見方

画面左上には次の3つのメニューがあります。

- 階級図を見る
- 商圏登録
- 設定

通常は「階級図を見る」から操作を始めます。

## 基本的な使い方

### 1. 階級図を開く

左上の「階級図を見る」を押します。初回起動時は、このボタンが点滅し、自動でドロワーが開きます。

### 2. 表示する地図の種類を選ぶ

ドロワーの「メニュー」タブで、表示したい主題図の種類を選びます。

- 都道府県単位の地図
- 市区町村単位の地図
- 町丁単位の地図
- あさひる統計の地図

選択すると、地図の種類に応じて「エリア」または「統計」へ進みます。

### 3. エリアを選ぶ

「エリア」タブで表示対象の地域を選びます。

- 通常の主題図では、一覧から地域を選択します
- あさひる統計では、先に商圏登録が必要です

地図上のクリックで地域追加が有効な画面では、未選択エリアをクリックして追加できる場合があります。

### 4. 統計を選ぶ

「統計」タブで、地図に表示する統計項目を選びます。選択した統計に応じて、地図の色分けが更新されます。

## 凡例編集

統計を表示すると、地図上に凡例が表示されます。凡例の下にある「編集」を押すと、凡例編集ダイアログが開きます。

### 凡例編集でできること

- 色のテーマを切り替える
- 区分数を変更する
- データ性質を切り替える
- 各階級の色を個別に変更する
- 各階級の開始値を調整する

### 基本手順

1. 地図に統計を表示する。
2. 凡例の「編集」を押す。
3. 必要に応じてテーマと区分数を調整する。
4. 各階級の色や開始値を調整する。
5. 「OK」を押して反映する。

### テーマと区分数

凡例編集ダイアログの上部では、配色テーマと区分数を変更できます。

- データ性質は「定量」「分岐」「定性」から選びます
- 区分数はテーマに応じて選択できる範囲が変わります
- カラースキームを選ぶと、凡例の色がまとめて切り替わります

区分数の目安は次のとおりです。

- 定量: 3から9
- 分岐: 3から11
- 定性: 3から12

### 階級ごとの編集

ダイアログ下部の一覧では、階級ごとの色と開始値を編集できます。

- 左側の色見本を押すと、その階級の色を変更できます
- 開始値はプラスとマイナスのボタン、または直接入力で変更できます
- 右端にはその階級の終了値が表示されます

開始値を変更すると、前後の階級とのつながりが保たれるように、隣の階級の値も自動で調整されます。

### 反映と取り消し

- 「OK」で変更を地図に反映します
- 「キャンセル」でダイアログを閉じ、編集前の状態に戻します

凡例の設定は保存対象に含まれるため、設定をダウンロードしておくとあとから同じ色分けを再利用できます。

## 商圏登録

左上の「商圏登録」を押すと、商圏登録ドロワーが開きます。商圏登録には2つの方法があります。

### 円商圏

- 半径を入力します
- 必要に応じて候補メニューから距離を選びます
- 色を設定します
- 地図をクリックして商圏を登録します

### 到達圏

- 交通手段を選びます
- 移動種別を選びます
- 分またはメートルで範囲を入力します
- 色を設定します
- 地図をクリックして到達圏を登録します

## あさひる統計の利用手順

あさひる統計では、まず商圏を登録してから階級図を表示します。

1. 「階級図を見る」を開く
2. あさひる統計のメニューを選ぶ
3. 「エリア」タブで「商圏登録」を押す。
4. 円商圏または到達圏を登録する
5. 商圏に応じた対象地域を確認する
6. 「統計」タブで表示項目を選ぶ。

## 設定

左上の「設定」では、次の操作ができます。

- 保存データのダウンロード
- 保存データのアップロード
- 前回の状態の復元
- ライト／ダークモードの切り替え
- 初回案内の再表示
- ヘルプの表示

### 保存と復元

設定データをJSONでダウンロードできます。アップロードすると、以前の状態を復元できます。アップロード後はページが再読み込みされます。

## はじめて使うときのオススメ手順

1. 「階級図を見る」を開く
2. 「メニュー」で主題図の種類を選ぶ。
3. 「エリア」で地域を選ぶ。
4. 「統計」で表示したい指標を選ぶ。
5. 必要なら「商圏登録」で範囲を追加する
6. 「設定」から保存する

## 困ったとき

### ヘルプが見つからない

「設定」ドロワーの関連情報から「ヘルプ」を開いてください。

### 初回案内をもう一度見たい

「設定」ドロワーの関連情報から「初回案内をもう一度見る」を押してください。

### 地図が意図どおりに切り替わらない

選択中のメニュー、エリア、統計の組み合わせを見直してください。あさひる統計では商圏登録が前提になります。
