# 47maps 制限事項

このページでは、47mapsを利用するうえで事前に把握しておきたい制限事項をまとめます。

## 利用環境

- JavaScriptが無効な環境では動作しません
- モダンブラウザーを前提としています
- 地図表示にはネットワーク接続が必要です

## 地図表示

- ベースマップや地図タイルの表示は外部サービスの状態に依存します
- 通信状況が不安定な場合、地図や統計データの表示が遅れることがあります
- 大量のデータを同時に表示すると、端末性能によって描画が重くなる場合があります

## 主題図

- 表示できる内容は、選択した地図種別と統計項目の組み合わせに依存します
- 地図種別によっては選択できる地域や統計が異なります
- 統計データが存在しない項目や地域では、期待した表示にならない場合があります

## 凡例編集

- 凡例編集は、統計表示後に凡例が表示されている場合のみ利用できます
- 区分数はデータ性質ごとに上限があります
  - 定量: 3から9
  - 分岐: 3から11
  - 定性: 3から12
- 開始値を変更すると、隣接する階級の境界値も自動で調整されます

## 商圏登録

- 商圏は地図上をクリックして登録します
- 入力できる範囲は画面上の入力制約に従います
- 到達圏の結果は交通手段や範囲設定に依存します
- あさひる統計では、先に商圏登録を行う前提の操作があります

## 保存と復元

- 保存データはJSONファイルとして扱われます
- アップロード時は現在の状態が上書きされます
- 復元後はページの再読み込みが発生します
- 異なるバージョン間では、保存データの互換性に差が出る可能性があります

## 補足

運用環境や組み込み先アプリケーションによって、追加の制約が発生する場合があります。必要に応じて、利用中のアプリケーション固有の設定や運用ルールも確認してください。
